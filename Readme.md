# MeloFlow

Android music-video discovery app (Kotlin · Jetpack Compose · Material 3 · Media3).
**Status: Phase 1 — buildable skeleton only. No product features yet.**

## Requirements
- Android Studio (current stable), JDK 17+, Android SDK Platform 35

## Open & build
1. Open the folder in Android Studio and let Gradle sync.
2. If `gradlew` is missing, run `gradle wrapper --gradle-version 8.9` once (the wrapper JAR is not included).
3. `./gradlew :app:assembleDebug`

Dependency versions live in `gradle/libs.versions.toml` — verify them on first sync.
Full documentation arrives in Phase 11.
